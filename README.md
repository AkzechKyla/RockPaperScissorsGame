# Rock, Paper, Scissors Game

A cat-themed Rock, Paper, Scissors game written in **HTML**, **CSS**, and **JavaScript**

Play the game here: [https://akzechkyla.github.io/Rock-Paper-Scissors-Game/rock-paper-scissors.html](https://akzechkyla.github.io/RockPaperScissorsGame/)

## Features
- Cat-themed user interface
- Play Rock, Paper, Scissors with a computer.
- Scoring system
